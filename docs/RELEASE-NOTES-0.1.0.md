# Violet 紫麦 0.1.0 — 开发预览（草稿）

本版本仍在验收，暂不作为普通用户正式发行。

## 功能
- 原生 macOS 菜单栏紫色麦克风，一键回溯，⌘⇧V 全局快捷键。
- 30 分钟本地环形音频缓冲，麦克风与系统音频独立来源。
- 波形两端拖动选段、1–30 分钟回溯、试听。
- 用户自配 ElevenLabs、Gemini 或兼容音频转写接口。
- 转写并复制；关窗后台转写并保存 Markdown。
- 可配置保存目录，独立历史文件和供 agent 读取的 latest.md。

## 已验证
合成音频真实 API 转写、两端裁剪、系统剪贴板、关窗后台保存、agent 文件读取、快捷键唤回、本机 DMG 安装与启动、缓冲容量及暂停间隔逻辑。macOS CI 构建和测试已通过先前提交；发布前需核对当前提交的 CI。

## 尚待完成
真实麦克风和系统音频权限后的采集、实际设备/睡眠恢复、Gemini 实际服务验收、Developer ID 签名与 Apple 公证。

未公证开发产物可能被 Gatekeeper 拦截。不要关闭系统安全机制来使用本预览。开发者可从源码构建。
